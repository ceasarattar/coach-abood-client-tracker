============================================================
  COACH ABOOD CLIENT TRACKER  —  START HERE
============================================================

Do these 3 things, in order:

  1. INSTALL PYTHON (one time)
     Go to https://www.python.org/downloads/  -> Download -> Run installer
     IMPORTANT: tick "Add python.exe to PATH" on the first screen.

  2. ADD THE SECRET FILE
     Put the file  credentials.json  (Ceasar sends it to you)
     into THIS folder — the same folder as setup.bat.

  3. RUN SETUP
     Double-click  setup.bat
     It installs everything and asks you to paste your master
     spreadsheet ID. When it finishes you'll have a
     "Coach Dashboard" icon on your Desktop.

------------------------------------------------------------
To open the app later: double-click the Desktop icon.
Stuck? Open the app and click "Help & Setup" on the left for
a click-by-click guide that checks what's done for you.
