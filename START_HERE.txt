============================================================
  COACH ABOOD CLIENT TRACKER  —  START HERE
============================================================

This app runs HOSTED: one shared web address that you and Abood
both use. Same data for both, nothing to install on his PC,
nothing to keep in sync.

>> TO PUT IT ONLINE  (one time, ~15 minutes, free)
     Open  DEPLOY.md  and follow the checklist:
     Neon database  +  Google service account  +  Render.

>> TO GIVE IT TO ABOOD
     Send him the URL + passcode and the file  FOR-ABOOD.txt.
     He opens the link, types the passcode, and (optionally)
     clicks "Install" to get a desktop icon. That's it.

>> TO RUN IT ON YOUR OWN MACHINE  (development only)
     1. Install Python 3.10+  (on Windows tick "Add to PATH").
     2. Double-click  setup.bat   (or run  ./setup.sh ).
     3. It opens the app at  http://127.0.0.1:5000

More detail:  README.md   and   DEPLOY.md
