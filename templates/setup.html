The server has no Google service account configured. Connect it once (this replaces the old per-user login — it never expires):

  1. Go to console.cloud.google.com → your project → APIs & Services → Library → enable Google Sheets API.
  2. IAM & Admin → Service Accounts → Create service account. Then Keys → Add key → JSON and download it.
  3. Copy the service account's email and share the master sheet and every client sheet with it (Editor).
  4. Set the JSON as the GOOGLE_SERVICE_ACCOUNT_JSON environment variable on the host (or save it as service_account.json locally) and set MASTER_SHEET_ID. Redeploy.

Prefer click-by-click? Open the Help & Setup guide — it has a live checklist and step-by-step instructions. Full details are also in README.md.
