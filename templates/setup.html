credentials.json is missing. Follow these steps once to connect to Google Sheets:

  1. Go to console.cloud.google.com → New Project → name it coach-dashboard
  2. APIs & Services → Library → enable Google Sheets API
  3. OAuth consent screen → External → Testing
    Add your Gmail as a Test User & add scope spreadsheets (read + write)
  4. Credentials → Create Credentials → OAuth client ID → Desktop app
    Download JSON → save as credentials.json in the project folder
  5. Restart the server — a browser tab will open for Google sign-in

Full instructions are in README.md in the project folder.
