{# ── Step-by-step ────────────────────────────────────────────────────── #}
1 {{ icon('download',16) }} Add the Google connection file

The app talks to Google Sheets through a small key file called credentials.json. It's a secret, so it is not included in the download.

  1. Ceasar sends you credentials.json separately (email/USB/drive).
  2. Save it, then move it into the project folder — the same folder that contains setup.bat and app.py.
  3. That's it. Don't rename it.

Advanced (Ceasar): it's an OAuth Desktop app client from Google Cloud Console → APIs & Services → Credentials, with the Google Sheets API enabled.

2 {{ icon('sheet',16) }} Run setup & link the master sheet
  1. In the project folder, double-click setup.bat. (If Windows shows a blue warning: More info → Run anyway.)
  2. It installs everything automatically. When it asks, paste your master spreadsheet ID and press Enter.
  3. The ID is the long code in the master sheet's web address:
    docs.google.com/spreadsheets/d/THIS-LONG-CODE/edit
  4. It finishes by making a Coach Dashboard shortcut on your Desktop.
3 {{ icon('check',16) }} Launch & sign in to Google
  1. Double-click the Coach Dashboard icon on your Desktop.
  2. Your browser opens the dashboard, and a Google sign-in tab appears.
  3. Sign in with the Google account that owns the spreadsheets and click Allow. (If it says "unverified," click Advanced → Go to… → Allow — it's your own app.)

Logins can expire ~weekly while the Google project is in "Testing." If that happens, just use the Re-sign in button above. Ceasar can "Publish" the project to make it permanent.

4 {{ icon('sparkles',16) }} One-click new clients (optional)

Without this, the New-Client wizard still works — it just asks you to click Coach Tools → Generate Client Template in the master sheet and paste the new sheet link back. With it, the whole thing is one click.

  1. Open the master sheet → Extensions → Apps Script.
  2. Paste the contents of apps_script/Code.gs from the project.
  3. Set WEBAPP_SECRET to a long random string. Deploy → New deployment → Web app (Execute as: Me, Access: Anyone). Copy the /exec URL.
  4. Put the URL + the same secret into the project's .env as TEMPLATE_WEBAPP_URL and TEMPLATE_WEBAPP_SECRET (the setup script can do this for you), then restart the app.
Open the New-Client wizard
5 {{ icon('flame',16) }} Cronometer nutrition sync (optional)
  1. Open a client → Cronometer → enter their Cronometer email + password → Save credentials (stored encrypted on this PC only — never in Google or GitHub).
  2. Click Sync nutrition. Their daily calories flow into the Weight tab and the calorie chart.

If a client's Cronometer has 2-factor auth on, sync can't pass it — turn 2FA off for that account to use sync.

6 {{ icon('users',16) }} Using it day to day
  • Open: double-click the Desktop shortcut. Already open? It just reopens the browser — never a second copy.
  • Close: close the small black window the shortcut opened.
  • Client dots: 🟢 on track · 🟡 needs a look · 🔴 overdue / not logging / payment late.
  • Add a client you already have a sheet for: Add client → paste their sheet link.
  • Brand-new client: Add client → Start guided setup.
  • Log weight / payment: open a client → Log entry (dates are dd/mm/yyyy).
  • Something looks off? send Ceasar logs\dashboard.log from the project folder.
