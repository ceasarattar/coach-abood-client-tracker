1 {{ icon('rocket',16) }} Install it as an app (optional)

This runs in your browser, but you can pin it like a real desktop app:

  • Edge/Chrome (computer): open the menu (⋯) → Apps → Install this site as an app. You get an icon and a window with no address bar.
  • Phone: Share → Add to Home Screen.

No download, no Python, nothing to set up — it always loads the latest version because it's the same live site.

2 {{ icon('userplus',16) }} Add clients
  • Already have a sheet for them? Add client → paste the client's Google Sheet link. (Make sure that sheet is shared with the service account email shown above.)
  • Brand-new client? Add client → Start guided setup to build their program and generate the sheet.
Add an existing sheet New-client wizard
3 {{ icon('sparkles',16) }} One-click new clients (optional)

Without this, the New-Client wizard still works — it just asks you to click Coach Tools → Generate Client Template in the master sheet and paste the new sheet link back. With it, the whole thing is one click.

  1. Open the master sheet → Extensions → Apps Script.
  2. Paste the contents of apps_script/Code.gs from the project.
  3. Set WEBAPP_SECRET to a long random string. Deploy → New deployment → Web app (Execute as: Me, Access: Anyone). Copy the /exec URL.
  4. Add the URL + the same secret as the TEMPLATE_WEBAPP_URL and TEMPLATE_WEBAPP_SECRET environment variables on the host (Render → Environment), then redeploy.
4 {{ icon('flame',16) }} Cronometer nutrition sync (optional)
  1. Open a client → Cronometer → enter their Cronometer email + password → Save credentials (stored encrypted in the shared database — never in Google or GitHub).
  2. Click Sync nutrition. Their daily calories flow into the Weight tab and the calorie chart.

If a client's Cronometer has 2-factor auth on, sync can't pass it — turn 2FA off for that account to use sync.

5 {{ icon('users',16) }} Using it day to day
  • Open: the bookmark or the installed app icon. You and Ceasar always see the same live data.
  • Client dots: 🟢 on track · 🟡 needs a look · 🔴 overdue / not logging / payment late.
  • Log weight / payment: open a client → Log entry (dates are dd/mm/yyyy).
  • Sign out: use the “Sign out” link in the sidebar.
  • Something looks off? Ceasar can check the same screen and the server logs.
6 {{ icon('layers',16) }} How it's wired (for Ceasar)
  • Hosting: one Render web service; both users share it.
  • Database: Neon Postgres (DATABASE_URL) holds the workout library + client registry. Inspect/fix data in the Neon console.
  • Sheets: a Google service account (GOOGLE_SERVICE_ACCOUNT_JSON) — share every sheet with its email. No more credentials.json or weekly re-login.
  • Login: shared APP_PASSCODE.
  • Full steps are in DEPLOY.md.
