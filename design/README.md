# Claude Design output goes here

Drop the files Claude Design exported (HTML/CSS/components, screenshots, notes)
into this folder and commit them. The next Claude Code session will read them
from here and rework `templates/*` + `static/style.css` to match, preserving the
UI contract documented in [`../docs/PROJECT_STATUS.md`](../docs/PROJECT_STATUS.md).

Nothing here is loaded by the app — it's a staging area for the redesign.
